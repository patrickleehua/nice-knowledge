# 星轨网关运维手册

## 组件定位

星轨网关是所有外部流量进入平台的唯一入口，承担协议卸载、限流和路由分发三项职责。
星轨网关部署在沧澜集群，与集群内其他服务通过内网直连，不经过公网回环。

## 身份校验

星轨网关自身不保存任何账号信息，也不判断用户身份。每一个进来的请求，星轨网关都会
转交澜图鉴权服务校验，拿到校验结论后再决定放行还是拒绝。澜图鉴权服务返回的结论只有
三种：放行、拒绝、需要二次验证。

这个设计的用意是让网关保持无状态：星轨网关的任意一个实例都可以随时被替换掉，重启后
不需要恢复任何本地数据。

## 限流策略

星轨网关的默认限流阈值是每客户端每分钟 240 次请求，超出后返回 429。压测场景可以临时
调到 2000，但必须在压测结束后手动改回，星轨网关不会自动恢复这个值。

限流计数窗口是滚动 60 秒，不是自然分钟。灰度期间曾经用过自然分钟窗口，因为跨分钟瞬间
容易被打穿，后来改掉了。

## 超时与重试

星轨网关对下游的调用超时统一是 3 秒。超时后只重试一次，且只对幂等请求重试。非幂等请求
超时后直接返回 504，不做任何重试，避免重复扣款这类问题。

## 灰度发布

星轨网关的灰度按请求头 `X-Release-Channel` 分流，不按用户 ID 哈希。运维需要注意：灰度
配置改动后有最多 30 秒的生效延迟，这段时间内新旧配置会同时生效。
